# Pastelaria da Vila

Site de uma pastelaria fictícia da Vila Hortência, em Sorocaba, feito para a atividade da **Aula 06 – CSS: Seletores, Cores, Tipografia e Layouts Básicos** da disciplina de Web Design (Facens).

A página tem cabeçalho com menu, destaque inicial, cardápio (pastéis salgados, doces e bebidas), promoções da semana, nossa história, avaliações de clientes, horário e endereço, rodapé e botão fixo de voltar ao topo. Foi feita só com HTML e CSS, sem JavaScript, e todo o CSS fica no arquivo externo `style.css`.

## Propriedades da aula

`color`, `background-color`, `font-family`, `font-size`, `margin`, `padding`, `border`, `width`, `height`, `display` (block, inline e flex), `position` (relative, absolute e fixed), `top`, `right`, `bottom`, `left`, `text-align` (center e justify) e seletores de classe (`.`) e de ID (`#`).

## Propriedades adicionais

- **Design:** `border-radius`, `box-shadow`, `text-shadow`, `line-height`, `letter-spacing`, `max-width`, `text-transform`, `object-fit`, `z-index`
- **Interatividade:** `:hover`, `:focus`, `transition`, `transform`, `cursor`, `opacity`, `scroll-behavior`
- **Responsividade:** `@media` para tablet (até 900px) e celular (até 600px), `flex-wrap`, `gap`

## Como abrir

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador (dois cliques no arquivo ou, no VS Code, com a extensão Live Server).
3. As fotos ficam na pasta `imagens/`. A lista das fotos está em `imagens/LEIA-ME.txt`; sem elas o site continua funcionando e mostra um bloco no lugar de cada foto.
